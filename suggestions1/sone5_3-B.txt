## 先說明:與你規格的出入與新增決策

| 項目 | 說明 |
|---|---|
| **`step()` 沒有 `dt` 參數** | 邏輯 tick 固定 40ms,一次 `step()` 就是一個 tick。可變 `dt` 會讓同一個種子在不同節奏下產生不同軌跡,和「60Hz/144Hz 邏輯一致」的目標相衝突。真實時間到 tick 的換算由 3-C 的累加器負責 |
| **補丁 `targets.ts`** | 穿透投射物需要「每個目標只命中一次」。3-A 的 `findNearestUnit` 只能排除一個 id,所以新增 `findNearestUnitSkipping`(純新增,不改動既有方法與測試) |
| **生成的 tick 語意** | `spawn()` 產生 `INIT` 記錄,在**下一次** `step()` 才啟用並移動,啟用當 tick 就會移動一次。在 step 內(鉤子裡)生成的投射物同樣到下一個 tick 才啟用,與槽位順序無關。這由每槽位的 `spawnTick` 保證 |
| **行為層私有狀態** | `MissileRuntime` 沒有「基準方向」之類的欄位。我加了 `BehaviorEnv.state`(`Float64Array`,每槽位 `STATE_STRIDE = 4` 個浮點數,生成時清零),F04 用它存基準方向,F03 螺旋之後也會用到。3-A 的型別完全沒動 |
| **碰撞** | 目標視為一個點,命中條件是「點在投射物碰撞圓內」。單位的體積請折進 `radiusPx`。每 tick 只在終點檢測。**高速投射物可能穿過小目標**,請讓 `radiusPx ≳ speed/2`,或之後加掃掠檢測 |
| **命中記憶** | 每顆投射物記住最近 8 個命中過的目標(環形緩衝)。無限穿透時,同一 tick 最多處理 8 次命中,超過的留到下個 tick。這同時保證命中迴圈必然終止 |
| **爆裂時長** | `durationTicks = D`:在轉入 `EXPLODING` 的那個 tick 之後再過 D−1 個 tick 仍是 `EXPLODING`,第 D 個 tick 變 `DEAD`。D=0 立即回收 |
| **子投射物** | `explosion.spawnMissileId` 在爆裂瞬間生成,繼承位置、方向與陣營。管理器建構時會檢查 id 是否存在、有沒有循環(A→B→A)。F07 的環形或隨機發射圖樣不在本輪範圍 |
| **耗盡策略** | `'reject'`(預設):`spawn` 回傳 `NO_HANDLE` 並計數。`'evict-oldest'`:先回收 `EXPLODING` 中最接近結束的,否則回收存活最久的,同分取較小槽位 |
| **「零配置」的範圍** | 池、free-list、命中記憶、行為狀態全部預先配置;每 tick 路徑只用數字與預先配置的物件。我沒有放堆積量測,因為 `types: []` 下沒有 `process`。請用 Chrome Performance 面板或 `node --trace-gc` 實測 |
| **動畫幀** | `MissileSpec` 沒有幀數與動畫速度欄位,所以管理器不推進 `animAcc/animFrame`,留給 3-C 的繪製器與動畫表 |

## 補丁:src/targets.ts(貼進 `TargetRegistry` 類別內,放在 `findNearestUnit` 之後)

```ts
  /**
   * 同 findNearestUnit,但略過 skip[skipOffset .. skipOffset+skipCount) 內列出的 id。
   * 供穿透投射物「每個目標只命中一次」使用。零配置。
   */
  findNearestUnitSkipping(
    x: number,
    y: number,
    radius: number,
    team: number,
    skip: Int32Array,
    skipOffset: number,
    skipCount: number,
  ): number {
    if (!Number.isFinite(x) || !Number.isFinite(y) || !Number.isFinite(radius) || radius < 0) {
      throw new RangeError(`invalid search (x=${x}, y=${y}, radius=${radius})`);
    }
    if (
      !Number.isInteger(skipOffset) ||
      !Number.isInteger(skipCount) ||
      skipOffset < 0 ||
      skipCount < 0 ||
      skipOffset + skipCount > skip.length
    ) {
      throw new RangeError(`invalid skip range (${skipOffset}, ${skipCount}) for length ${skip.length}`);
    }
    const r2 = radius * radius;
    let bestId = NO_TARGET;
    let bestD2 = Infinity;
    const p = this.scratch;
    for (let i = 0; i < this.list.length; i++) {
      const t = this.list[i]!;
      if (!(t instanceof UnitTarget) || t.team !== team) continue;
      let skipped = false;
      for (let k = 0; k < skipCount; k++) {
        if (skip[skipOffset + k] === t.id) {
          skipped = true;
          break;
        }
      }
      if (skipped) continue;
      if (!t.resolve(p)) continue;
      const dx = p.x - x;
      const dy = p.y - y;
      const d2 = dx * dx + dy * dy;
      if (d2 > r2) continue;
      if (d2 < bestD2 || (d2 === bestD2 && t.id < bestId)) {
        bestD2 = d2;
        bestId = t.id;
      }
    }
    return bestId;
  }
```

```ts
    expect(reg.findNearestUnitSkipping(0, 0, 100, 1, skip, 3, 1)).toBe(a.id);
```

## src/pool.ts

```ts
/**
 * pool.ts — 投射物物件池(預先配置 + free-list + generation handle)
 *
 * 設計:
 *  - 建構時一次配置 capacity 筆 MissileRuntime,之後永不新增、永不丟棄。
 *  - free-list 以 Int32Array 串成鏈(LIFO):acquire/release 都是 O(1),零配置。
 *  - handle = generation × 65536 + 槽位索引,純數字(不配置物件)。
 *    釋放時 resetMissileRuntime 會遞增 generation,所以舊 handle 立刻失效;
 *    即使槽位被重用,舊 handle 也不會指到新的投射物。
 *  - 迭代請用 `for (i = 0; i < highWater; i++) at(i)`:highWater 是曾經使用過的最大槽位 + 1,
 *    不會隨釋放而縮小,迴圈成本與「峰值併發」而非 capacity 成正比。
 *
 * 限制:
 *  - capacity ≤ 65536(索引占 16 位)。
 *  - generation 為 uint32,同一槽位重用 2^32 次後 handle 會重複,實務上不可能發生。
 *  - 本類別不分派事件鉤子。需要鉤子請透過 MissileManager.kill()。
 */

import {
  MissileState,
  createMissileRuntime,
  resetMissileRuntime,
  type MissileRuntime,
} from './missile-types.js';

export const NO_HANDLE = -1;
export const POOL_INDEX_RADIX = 65536;
export const MAX_POOL_CAPACITY = POOL_INDEX_RADIX;

export class MissileObjectPool {
  readonly capacity: number;

  private readonly records: MissileRuntime[];
  private readonly nextFree: Int32Array;
  private readonly live: Uint8Array;
  private freeHead = 0;
  private liveN = 0;
  private hw = 0;
  private peak = 0;
  private exhausted = 0;
  private acquired = 0;
  private released = 0;

  constructor(capacity: number) {
    if (!Number.isInteger(capacity) || capacity < 1 || capacity > MAX_POOL_CAPACITY) {
      throw new RangeError(`capacity must be an integer in [1, ${MAX_POOL_CAPACITY}], got ${capacity}`);
    }
    this.capacity = capacity;
    this.records = Array.from({ length: capacity }, (_, i) => createMissileRuntime(i));
    this.nextFree = new Int32Array(capacity);
    this.live = new Uint8Array(capacity);
    this.rebuildFreeList();
  }

  get liveCount(): number {
    return this.liveN;
  }
  get freeCount(): number {
    return this.capacity - this.liveN;
  }
  /** 曾使用過的最大槽位 + 1。迭代上限。 */
  get highWater(): number {
    return this.hw;
  }
  get peakLive(): number {
    return this.peak;
  }
  /** acquire() 因池已滿而失敗的累計次數。 */
  get exhaustedCount(): number {
    return this.exhausted;
  }
  get acquiredTotal(): number {
    return this.acquired;
  }
  get releasedTotal(): number {
    return this.released;
  }

  /**
   * 取出一筆空閒記錄,狀態設為 INIT,其餘欄位為乾淨預設值。
   * 池已滿回傳 null 並累計 exhaustedCount。
   */
  acquire(): MissileRuntime | null {
    if (this.freeHead === -1) {
      this.exhausted++;
      return null;
    }
    const idx = this.freeHead;
    this.freeHead = this.nextFree[idx]!;
    this.nextFree[idx] = -1;
    this.live[idx] = 1;
    this.liveN++;
    this.acquired++;
    if (this.liveN > this.peak) this.peak = this.liveN;
    if (idx + 1 > this.hw) this.hw = idx + 1;
    const rt = this.records[idx]!;
    rt.state = MissileState.INIT;
    return rt;
  }

  /** 記錄 → handle。只對仍存活的記錄有意義。 */
  handleOf(rt: MissileRuntime): number {
    return rt.generation * POOL_INDEX_RADIX + rt.handle;
  }

  /** handle → 記錄。過期、已釋放、格式錯誤一律回傳 null。 */
  get(handle: number): MissileRuntime | null {
    if (!Number.isInteger(handle) || handle < 0) return null;
    const idx = handle % POOL_INDEX_RADIX;
    if (idx >= this.capacity || this.live[idx] === 0) return null;
    const rt = this.records[idx]!;
    return rt.generation * POOL_INDEX_RADIX + idx === handle ? rt : null;
  }

  isValid(handle: number): boolean {
    return this.get(handle) !== null;
  }

  /** 依索引取記錄(迭代用,不檢查範圍;請用 0 ≤ i < highWater)。可能是 DEAD 狀態的空閒槽位。 */
  at(index: number): MissileRuntime {
    return this.records[index]!;
  }

  /** 以 handle 釋放。過期或重複釋放回傳 false。 */
  release(handle: number): boolean {
    const rt = this.get(handle);
    return rt === null ? false : this.releaseRecord(rt);
  }

  /** 以記錄釋放:重置所有欄位、遞增 generation、放回 free-list 頭。重複釋放回傳 false。 */
  releaseRecord(rt: MissileRuntime): boolean {
    const idx = rt.handle;
    if (idx < 0 || idx >= this.capacity || this.records[idx] !== rt || this.live[idx] === 0) {
      return false;
    }
    resetMissileRuntime(rt);
    this.live[idx] = 0;
    this.nextFree[idx] = this.freeHead;
    this.freeHead = idx;
    this.liveN--;
    this.released++;
    return true;
  }

  /** 釋放全部存活記錄並重建 free-list。計數器保留。 */
  clear(): void {
    for (let i = 0; i < this.hw; i++) {
      if (this.live[i] === 1) {
        resetMissileRuntime(this.records[i]!);
        this.released++;
      }
    }
    this.liveN = 0;
    this.live.fill(0);
    this.rebuildFreeList();
  }

  /** 診斷用(會配置記憶體,請勿放在熱路徑)。回傳空陣列代表結構完整。 */
  checkIntegrity(): string[] {
    const errors: string[] = [];
    const cap = this.capacity;
    const seen = new Uint8Array(cap);
    let n = 0;
    let cur = this.freeHead;
    while (cur !== -1) {
      if (cur < 0 || cur >= cap) {
        errors.push(`free list index out of range: ${cur}`);
        break;
      }
      if (seen[cur]) {
        errors.push(`free list cycle or duplicate at slot ${cur}`);
        break;
      }
      seen[cur] = 1;
      n++;
      if (this.live[cur] === 1) errors.push(`live slot ${cur} is in the free list`);
      if (this.records[cur]!.state !== MissileState.DEAD) errors.push(`free slot ${cur} is not DEAD`);
      cur = this.nextFree[cur]!;
    }
    if (n !== cap - this.liveN) errors.push(`free list length ${n} != capacity - live (${cap - this.liveN})`);
    let flags = 0;
    for (let i = 0; i < cap; i++) if (this.live[i] === 1) flags++;
    if (flags !== this.liveN) errors.push(`live flags ${flags} != liveCount ${this.liveN}`);
    return errors;
  }

  private rebuildFreeList(): void {
    const cap = this.capacity;
    for (let i = 0; i < cap - 1; i++) this.nextFree[i] = i + 1;
    this.nextFree[cap - 1] = -1;
    this.freeHead = 0;
  }
}
```

## src/behaviors.ts

```ts
/**
 * behaviors.ts — 行為原語:F01 直線、F02 追蹤、F04 隨機折線
 *
 * 單位:全部是 Ground(地面未壓縮)像素 / tick,角度為度。
 * 螢幕 Y × 0.5 只在繪製端做,本檔完全不碰。
 *
 * 一個 tick 內,行為負責「轉向 + 移動」:
 *   速度 v' = clamp(v + accel, 0, maxSpeed),位置 += v'·(cosφ, sinφ)
 * 先更新速度再移動。生命週期、命中、爆裂由 MissileManager 負責。
 *
 * 擴充新家族:實作 BehaviorImpl、擴充 BehaviorParams 與 validateMissileSpec,再 register()。
 */

import type { FamilyId, MissileRuntime, MissileSpec } from './missile-types.js';
import { DEG2RAD, normalizeDeg } from './geometry.js';
import { lcgStep, lcgUnit } from './rng.js';
import { NO_TARGET, groundToPhi, type GroundPoint, type TargetRegistry } from './targets.js';

/** 每個槽位保留的行為私有浮點數個數。 */
export const STATE_STRIDE = 4;

export const StepOutcome = {
  /** 本 tick 正常移動。 */
  CONTINUE: 0,
  /** 本 tick 到達射程上限(位置已夾在射程終點)。 */
  RANGE: 1,
  /** 行為要求立刻到期(如追蹤彈失去目標且 fallback = 'expire')。 */
  EXPIRE: 2,
} as const;
export type StepOutcome = (typeof StepOutcome)[keyof typeof StepOutcome];

/** 行為執行期環境:由管理器持有,熱路徑重複使用,不配置。 */
export interface BehaviorEnv {
  readonly targets: TargetRegistry;
  /** 目前被處理的投射物所要攻擊的陣營(-1 = 無)。由管理器在每次呼叫前設定。 */
  team: number;
  /** 行為私有狀態:state[slot × STATE_STRIDE + k],生成時清零。 */
  readonly state: Float64Array;
  /** 暫存座標,供 resolve() 使用。 */
  readonly scratch: GroundPoint;
}

export function createBehaviorEnv(targets: TargetRegistry, slotCount: number): BehaviorEnv {
  return {
    targets,
    team: -1,
    state: new Float64Array(slotCount * STATE_STRIDE),
    scratch: { x: 0, y: 0 },
  };
}

export function clearBehaviorState(env: BehaviorEnv, slot: number): void {
  env.state.fill(0, slot * STATE_STRIDE, (slot + 1) * STATE_STRIDE);
}

export interface BehaviorImpl {
  readonly family: FamilyId;
  /** 生成時呼叫一次(rt 的位置、方向、速度、種子、targetId 已設好)。 */
  init(rt: MissileRuntime, spec: MissileSpec, env: BehaviorEnv): void;
  /** 每 tick 一次:轉向並移動。不得配置物件。 */
  update(rt: MissileRuntime, spec: MissileSpec, env: BehaviorEnv): StepOutcome;
}

// ───────────────────────── 共用:直線推進 ─────────────────────────

/**
 * 沿 rt.phi 推進一個 tick。
 *  - 速度:v' = clamp(v + accel, 0, maxSpeed)
 *  - 射程:rangePx 非 null 時,若本步會達到或超過射程,步長夾到剛好抵達,回傳 RANGE
 *    (不會超出射程終點;travelled 精確等於 rangePx)
 */
export function advanceLinear(rt: MissileRuntime, spec: MissileSpec): StepOutcome {
  const m = spec.motion;
  let v = rt.speed + m.accel;
  if (v > m.maxSpeed) v = m.maxSpeed;
  if (v < 0) v = 0;
  rt.speed = v;

  let step = v;
  let outcome: StepOutcome = StepOutcome.CONTINUE;
  const range = spec.lifetime.rangePx;
  if (range !== null) {
    const remaining = range - rt.travelled;
    if (step >= remaining) {
      step = remaining > 0 ? remaining : 0;
      outcome = StepOutcome.RANGE;
    }
  }

  const rad = rt.phi * DEG2RAD;
  rt.x += step * Math.cos(rad);
  rt.y += step * Math.sin(rad);
  rt.travelled = outcome === StepOutcome.RANGE && range !== null ? range : rt.travelled + step;
  return outcome;
}

function mismatch(expected: FamilyId, spec: MissileSpec): Error {
  return new Error(`behavior ${expected} used with spec "${spec.id}" of family ${spec.behavior.family}`);
}

// ───────────────────────── F01:直線 ─────────────────────────

export const F01_STRAIGHT: BehaviorImpl = {
  family: 'F01',
  init(): void {
    /* 無私有狀態 */
  },
  update(rt, spec): StepOutcome {
    return advanceLinear(rt, spec);
  },
};

// ───────────────────────── F02:追蹤 ─────────────────────────

/**
 * 每 tick 向目標轉向,每 tick 轉角上限 = turnRateDegPerTick(走最短弧)。
 *  - 生成時若 rt.targetId 有效就沿用,否則在 acquireRadiusPx 內找最近的敵方單位。
 *  - 目標失效後:reacquire = true 則重新索敵;找不到(或 reacquire = false)則依 fallback:
 *      'straight' → 沿當前方向直飛
 *      'expire'   → 本 tick 不移動,回傳 EXPIRE
 */
export const F02_HOMING: BehaviorImpl = {
  family: 'F02',

  init(rt, spec, env): void {
    const p = spec.behavior;
    if (p.family !== 'F02') throw mismatch('F02', spec);
    if (rt.targetId !== NO_TARGET && env.targets.resolve(rt.targetId, env.scratch)) return;
    rt.targetId = env.targets.findNearestUnit(rt.x, rt.y, p.acquireRadiusPx, env.team);
  },

  update(rt, spec, env): StepOutcome {
    const p = spec.behavior;
    if (p.family !== 'F02') throw mismatch('F02', spec);
    const sc = env.scratch;

    let have = false;
    if (rt.targetId !== NO_TARGET) {
      have = env.targets.resolve(rt.targetId, sc);
      if (!have) rt.targetId = NO_TARGET;
    }
    if (!have && p.reacquire) {
      rt.targetId = env.targets.findNearestUnit(rt.x, rt.y, p.acquireRadiusPx, env.team);
      if (rt.targetId !== NO_TARGET) {
        have = env.targets.resolve(rt.targetId, sc);
        if (!have) rt.targetId = NO_TARGET;
      }
    }

    if (have) {
      const dx = sc.x - rt.x;
      const dy = sc.y - rt.y;
      if (dx !== 0 || dy !== 0) {
        let d = normalizeDeg(groundToPhi(dx, dy) - rt.phi);
        if (d > 180) d -= 360; // 最短弧,範圍 (-180, 180]
        const lim = p.turnRateDegPerTick;
        if (d > lim) d = lim;
        else if (d < -lim) d = -lim;
        rt.phi = normalizeDeg(rt.phi + d);
      }
    } else if (p.fallback === 'expire') {
      return StepOutcome.EXPIRE;
    }
    return advanceLinear(rt, spec);
  },
};

// ───────────────────────── F04:隨機折線 ─────────────────────────

/**
 * 每隔 retargetEveryTicks 個 tick(以 ageTicks % N === 0 判定,所以第一個 tick 就會折一次),
 * 方向 = 基準方向 + U(−jitter, +jitter)。其餘 tick 直飛。
 *  - 基準方向:生成時的 phi;若 rt.targetId 有效,每次折線前改為朝向該目標的方位。
 *  - 隨機:用 rt.rngState 與 lcgStep/lcgUnit 推進,每次折線消耗恰好一個亂數。
 */
export const F04_ZIGZAG: BehaviorImpl = {
  family: 'F04',

  init(rt, spec, env): void {
    if (spec.behavior.family !== 'F04') throw mismatch('F04', spec);
    env.state[rt.handle * STATE_STRIDE] = rt.phi;
  },

  update(rt, spec, env): StepOutcome {
    const p = spec.behavior;
    if (p.family !== 'F04') throw mismatch('F04', spec);

    if (rt.ageTicks % p.retargetEveryTicks === 0) {
      const base = rt.handle * STATE_STRIDE;
      if (rt.targetId !== NO_TARGET) {
        if (env.targets.resolve(rt.targetId, env.scratch)) {
          const dx = env.scratch.x - rt.x;
          const dy = env.scratch.y - rt.y;
          if (dx !== 0 || dy !== 0) env.state[base] = groundToPhi(dx, dy);
        } else {
          rt.targetId = NO_TARGET;
        }
      }
      rt.rngState = lcgStep(rt.rngState);
      const jitter = (lcgUnit(rt.rngState) * 2 - 1) * p.stepJitterDeg;
      rt.phi = normalizeDeg(env.state[base]! + jitter);
    }
    return advanceLinear(rt, spec);
  },
};

// ───────────────────────── 註冊表 ─────────────────────────

export class BehaviorRegistry {
  private readonly map = new Map<FamilyId, BehaviorImpl>();

  register(impl: BehaviorImpl): this {
    if (this.map.has(impl.family)) throw new Error(`behavior already registered: ${impl.family}`);
    this.map.set(impl.family, impl);
    return this;
  }

  get(family: FamilyId): BehaviorImpl | undefined {
    return this.map.get(family);
  }

  has(family: FamilyId): boolean {
    return this.map.has(family);
  }
}

export function createDefaultBehaviors(): BehaviorRegistry {
  return new BehaviorRegistry().register(F01_STRAIGHT).register(F02_HOMING).register(F04_ZIGZAG);
}
```

## src/manager.ts

```ts
/**
 * manager.ts — MissileManager:一個 tick 的投射物邏輯推進
 *
 * 每次 step() 就是一個固定 40ms 的邏輯 tick(沒有 dt 參數,見交付說明)。
 *
 * 每筆記錄在一個 tick 內的處理順序:
 *   INIT(且生成於先前的 tick)→ 啟用(ACTIVATE 鉤子)→ 與 ACTIVE 相同處理
 *   ACTIVE:
 *     1. prev = curr,teleported = false(渲染插值用)
 *     2. 行為更新(轉向 + 移動)
 *     3. ageTicks++
 *     4. 碰撞:命中 → HIT 鉤子 → 穿透則繼續、否則 finish('hit')
 *     5. 到期:射程 → RANGE;lifetime 或行為要求 → LIFETIME → EXPIRE 鉤子 → finish('expire')
 *   EXPLODING:倒數,歸零後 DEAD
 *   finish:explodesOn(...) 為真 → EXPLODING(EXPLODE 鉤子、可選子投射物),否則 DEAD
 *
 * 鉤子可以安全地呼叫 spawn() / kill():每個處理步驟後都會檢查記錄是否仍是同一代、同一狀態。
 */

import {
  StepOutcome,
  clearBehaviorState,
  createBehaviorEnv,
  createDefaultBehaviors,
  type BehaviorEnv,
  type BehaviorImpl,
  type BehaviorRegistry,
} from './behaviors.js';
import { normalizeDeg } from './geometry.js';
import {
  ExpireReason,
  MissileEventKind,
  MissileState,
  canPierce,
  consumePierce,
  dispatchMissileEvent,
  explodesOn,
  validateMissileSpec,
  type MissileHooks,
  type MissileRuntime,
  type MissileSpec,
} from './missile-types.js';
import { MissileObjectPool, NO_HANDLE } from './pool.js';
import { deriveSeed } from './rng.js';
import { NO_TARGET, type TargetRegistry } from './targets.js';

export const NO_TEAM = -1;
/** 每顆投射物記住的最近命中目標數(也是單 tick 最大命中處理數)。 */
export const HIT_MEMORY = 8;

export type ExhaustionPolicy = 'reject' | 'evict-oldest';

export interface MissileManagerOptions {
  /** 規格表。建構後不可變;spawn 以索引(或 spawnById)引用。 */
  readonly specs: readonly MissileSpec[];
  readonly targets: TargetRegistry;
  /** 池容量,預設 512,上限 65536。 */
  readonly capacity?: number;
  /** 世界種子:每顆投射物的種子 = deriveSeed(worldSeed, 生成序號)。預設 1。 */
  readonly worldSeed?: number;
  readonly hooks?: MissileHooks | null;
  readonly behaviors?: BehaviorRegistry;
  readonly onExhausted?: ExhaustionPolicy;
}

export interface ManagerStats {
  spawned: number;
  rejected: number;
  evicted: number;
  hits: number;
  expired: number;
  exploded: number;
  died: number;
}

export class MissileManager {
  readonly pool: MissileObjectPool;
  readonly stats: ManagerStats = {
    spawned: 0,
    rejected: 0,
    evicted: 0,
    hits: 0,
    expired: 0,
    exploded: 0,
    died: 0,
  };
  /** 已執行的 step() 次數。 */
  tickCount = 0;

  private readonly specs: readonly MissileSpec[];
  private readonly specIndexById = new Map<string, number>();
  private readonly behaviors: BehaviorImpl[] = [];
  private readonly childIndex: Int32Array;
  private readonly env: BehaviorEnv;
  private readonly targets: TargetRegistry;
  private readonly hitTeam: Int16Array;
  private readonly hitMem: Int32Array;
  private readonly spawnTick: Float64Array;
  private readonly worldSeed: number;
  private readonly policy: ExhaustionPolicy;
  private hooks: MissileHooks | null;
  private spawnCounter = 0;

  constructor(opts: MissileManagerOptions) {
    const capacity = opts.capacity ?? 512;
    this.pool = new MissileObjectPool(capacity);
    this.targets = opts.targets;
    this.worldSeed = opts.worldSeed ?? 1;
    this.hooks = opts.hooks ?? null;
    this.policy = opts.onExhausted ?? 'reject';
    this.specs = [...opts.specs];

    const registry = opts.behaviors ?? createDefaultBehaviors();
    const n = this.specs.length;
    const errors: string[] = [];

    this.specs.forEach((s, i) => {
      for (const e of validateMissileSpec(s)) errors.push(`${s.id || `#${i}`}: ${e}`);
      if (this.specIndexById.has(s.id)) errors.push(`duplicate spec id: ${s.id}`);
      else this.specIndexById.set(s.id, i);
    });

    this.childIndex = new Int32Array(n).fill(-1);
    this.specs.forEach((s, i) => {
      const impl = registry.get(s.behavior.family);
      if (impl === undefined) errors.push(`${s.id}: no behavior registered for ${s.behavior.family}`);
      else this.behaviors.push(impl);

      const child = s.explosion?.spawnMissileId ?? null;
      if (child !== null) {
        const ci = this.specIndexById.get(child);
        if (ci === undefined) errors.push(`${s.id}: explosion.spawnMissileId "${child}" does not exist`);
        else this.childIndex[i] = ci;
      }
    });

    // 子投射物鏈每個節點最多一個後繼;走 n+1 步仍未結束就表示有循環。
    for (let i = 0; i < n; i++) {
      let cur = i;
      let k = 0;
      for (; k <= n; k++) {
        cur = this.childIndex[cur]!;
        if (cur < 0) break;
      }
      if (k > n) errors.push(`${this.specs[i]!.id}: spawn chain contains a cycle`);
    }

    if (errors.length > 0) throw new Error(`invalid missile specs:\n${errors.join('\n')}`);

    this.env = createBehaviorEnv(this.targets, capacity);
    this.hitTeam = new Int16Array(capacity).fill(NO_TEAM);
    this.hitMem = new Int32Array(capacity * HIT_MEMORY).fill(NO_TARGET);
    this.spawnTick = new Float64Array(capacity);
  }

  get liveCount(): number {
    return this.pool.liveCount;
  }

  setHooks(hooks: MissileHooks | null): void {
    this.hooks = hooks;
  }

  /** 規格 id → 索引,找不到回傳 -1。請在載入時查一次,熱路徑用索引。 */
  specIndexOf(id: string): number {
    return this.specIndexById.get(id) ?? -1;
  }

  specAt(index: number): MissileSpec {
    return this.specs[index]!;
  }

  // ───────────────────────── 生成與銷毀 ─────────────────────────

  /**
   * 生成投射物。
   * @param specIndex 規格索引
   * @param x,y       Ground 座標
   * @param phi       方向(度)
   * @param hitTeam   要攻擊的陣營;NO_TEAM(-1)= 不做碰撞
   * @param targetId  初始目標(NO_TARGET 則由行為自行索敵)
   * @returns handle;池滿且無法回收時回傳 NO_HANDLE
   */
  spawn(
    specIndex: number,
    x: number,
    y: number,
    phi: number,
    hitTeam: number = NO_TEAM,
    targetId: number = NO_TARGET,
  ): number {
    return this.spawnInternal(specIndex, x, y, phi, hitTeam, targetId, -1);
  }

  spawnById(
    id: string,
    x: number,
    y: number,
    phi: number,
    hitTeam: number = NO_TEAM,
    targetId: number = NO_TARGET,
  ): number {
    const idx = this.specIndexOf(id);
    if (idx < 0) throw new RangeError(`unknown missile spec id: ${id}`);
    return this.spawnInternal(idx, x, y, phi, hitTeam, targetId, -1);
  }

  /** 立即銷毀(會分派 DEAD 鉤子)。過期或已死亡的 handle 回傳 false。 */
  kill(handle: number): boolean {
    const rt = this.pool.get(handle);
    if (rt === null || rt.state === MissileState.DEAD) return false;
    this.terminate(rt);
    return true;
  }

  isAlive(handle: number): boolean {
    const rt = this.pool.get(handle);
    return rt !== null && rt.state !== MissileState.DEAD;
  }

  /** 清空所有投射物,不分派鉤子(換場景、從隱藏狀態恢復時使用)。 */
  clearAll(): void {
    this.pool.clear();
  }

  // ───────────────────────── 單 tick 推進 ─────────────────────────

  step(): void {
    this.tickCount++;
    const tick = this.tickCount;
    const pool = this.pool;
    const hw = pool.highWater;

    for (let i = 0; i < hw; i++) {
      const rt = pool.at(i);
      const st = rt.state;
      if (st === MissileState.DEAD) continue;
      if (st === MissileState.INIT) {
        // 本 tick 內才生成的(例如鉤子裡生成),留到下一個 tick 啟用,結果與槽位順序無關。
        if (this.spawnTick[i]! >= tick) continue;
        this.activate(rt);
        if (rt.state !== MissileState.ACTIVE) continue;
        this.stepActive(rt);
      } else if (st === MissileState.ACTIVE) {
        this.stepActive(rt);
      } else {
        this.stepExploding(rt);
      }
    }
  }

  // ───────────────────────── 內部實作 ─────────────────────────

  private spawnInternal(
    specIndex: number,
    x: number,
    y: number,
    phi: number,
    hitTeam: number,
    targetId: number,
    protectSlot: number,
  ): number {
    if (!Number.isInteger(specIndex) || specIndex < 0 || specIndex >= this.specs.length) {
      throw new RangeError(`specIndex out of range: ${specIndex}`);
    }
    if (!Number.isFinite(x) || !Number.isFinite(y) || !Number.isFinite(phi)) {
      throw new RangeError(`spawn position/direction must be finite, got (${x}, ${y}, ${phi})`);
    }
    if (!Number.isInteger(hitTeam) || hitTeam < -1 || hitTeam > 32767) {
      throw new RangeError(`hitTeam must be an integer in [-1, 32767], got ${hitTeam}`);
    }
    if (!Number.isInteger(targetId)) throw new RangeError(`targetId must be an integer, got ${targetId}`);

    let rt = this.pool.acquire();
    if (rt === null && this.policy === 'evict-oldest' && this.evictOne(protectSlot)) {
      rt = this.pool.acquire();
    }
    if (rt === null) {
      this.stats.rejected++;
      return NO_HANDLE;
    }

    const spec = this.specs[specIndex]!;
    const slot = rt.handle;
    rt.specIndex = specIndex;
    rt.ageTicks = 0;
    rt.x = x;
    rt.y = y;
    rt.prevX = x;
    rt.prevY = y;
    rt.phi = normalizeDeg(phi);
    rt.speed = spec.motion.speed;
    rt.travelled = 0;
    rt.pierceLeft = spec.collision.pierce;
    rt.hitCount = 0;
    rt.targetId = targetId;
    rt.rngState = deriveSeed(this.worldSeed, this.spawnCounter++);
    rt.explodeTicksLeft = 0;
    rt.teleported = true; // 生成不插值

    this.hitTeam[slot] = hitTeam;
    this.hitMem.fill(NO_TARGET, slot * HIT_MEMORY, (slot + 1) * HIT_MEMORY);
    this.spawnTick[slot] = this.tickCount;
    clearBehaviorState(this.env, slot);
    this.env.team = hitTeam;
    this.behaviors[specIndex]!.init(rt, spec, this.env);

    this.stats.spawned++;
    dispatchMissileEvent(this.hooks, MissileEventKind.SPAWN, rt, spec);
    return this.pool.handleOf(rt);
  }

  private activate(rt: MissileRuntime): void {
    rt.state = MissileState.ACTIVE;
    dispatchMissileEvent(this.hooks, MissileEventKind.ACTIVATE, rt, this.specs[rt.specIndex]!);
  }

  private stepActive(rt: MissileRuntime): void {
    const spec = this.specs[rt.specIndex]!;
    const team = this.hitTeam[rt.handle]!;

    rt.prevX = rt.x;
    rt.prevY = rt.y;
    rt.teleported = false;

    this.env.team = team;
    const outcome = this.behaviors[rt.specIndex]!.update(rt, spec, this.env);
    rt.ageTicks++;

    if (team >= 0 && this.resolveHits(rt, spec, team)) return;

    if (outcome === StepOutcome.RANGE) {
      this.expire(rt, spec, ExpireReason.RANGE);
    } else if (outcome === StepOutcome.EXPIRE || rt.ageTicks >= spec.lifetime.maxLifeTicks) {
      this.expire(rt, spec, ExpireReason.LIFETIME);
    }
  }

  /** 處理本 tick 的所有命中。回傳 true 表示該記錄已不再是 ACTIVE(轉換、死亡或被鉤子改動)。 */
  private resolveHits(rt: MissileRuntime, spec: MissileSpec, team: number): boolean {
    const gen = rt.generation;
    const base = rt.handle * HIT_MEMORY;
    for (let n = 0; n < HIT_MEMORY; n++) {
      const known = rt.hitCount < HIT_MEMORY ? rt.hitCount : HIT_MEMORY;
      const id = this.targets.findNearestUnitSkipping(
        rt.x,
        rt.y,
        spec.collision.radiusPx,
        team,
        this.hitMem,
        base,
        known,
      );
      if (id === NO_TARGET) return false;

      this.hitMem[base + (rt.hitCount % HIT_MEMORY)] = id;
      rt.hitCount++;
      this.stats.hits++;
      dispatchMissileEvent(this.hooks, MissileEventKind.HIT, rt, spec, id);
      if (rt.generation !== gen || rt.state !== MissileState.ACTIVE) return true;

      if (canPierce(rt.pierceLeft)) {
        rt.pierceLeft = consumePierce(rt.pierceLeft);
        continue;
      }
      this.finish(rt, spec, 'hit');
      return true;
    }
    return false;
  }

  private expire(rt: MissileRuntime, spec: MissileSpec, reason: ExpireReason): void {
    const gen = rt.generation;
    this.stats.expired++;
    dispatchMissileEvent(this.hooks, MissileEventKind.EXPIRE, rt, spec, reason);
    if (rt.generation !== gen || rt.state !== MissileState.ACTIVE) return;
    this.finish(rt, spec, 'expire');
  }

  private finish(rt: MissileRuntime, spec: MissileSpec, trigger: 'hit' | 'expire'): void {
    if (explodesOn(spec, trigger)) this.beginExplosion(rt, spec);
    else this.terminate(rt);
  }

  private beginExplosion(rt: MissileRuntime, spec: MissileSpec): void {
    const x = spec.explosion;
    if (x === null) {
      this.terminate(rt);
      return;
    }
    const gen = rt.generation;
    const slot = rt.handle;

    rt.state = MissileState.EXPLODING;
    rt.explodeTicksLeft = x.durationTicks;
    rt.speed = 0;
    this.stats.exploded++;
    dispatchMissileEvent(this.hooks, MissileEventKind.EXPLODE, rt, spec);
    if (rt.generation !== gen || rt.state !== MissileState.EXPLODING) return;

    const child = this.childIndex[rt.specIndex]!;
    if (child >= 0) {
      this.spawnInternal(child, rt.x, rt.y, rt.phi, this.hitTeam[slot]!, NO_TARGET, slot);
      if (rt.generation !== gen || rt.state !== MissileState.EXPLODING) return;
    }
    if (x.durationTicks === 0) this.terminate(rt);
  }

  private stepExploding(rt: MissileRuntime): void {
    rt.prevX = rt.x;
    rt.prevY = rt.y;
    rt.teleported = false;
    rt.ageTicks++;
    rt.explodeTicksLeft--;
    if (rt.explodeTicksLeft <= 0) this.terminate(rt);
  }

  /** 標為 DEAD → DEAD 鉤子(此時資料仍完整)→ 放回池。 */
  private terminate(rt: MissileRuntime): void {
    const spec = this.specs[rt.specIndex]!;
    rt.state = MissileState.DEAD;
    this.stats.died++;
    dispatchMissileEvent(this.hooks, MissileEventKind.DEAD, rt, spec);
    this.pool.releaseRecord(rt);
  }

  /** 池滿時回收一筆:優先 EXPLODING 中最接近結束的,否則存活最久的。同分取較小槽位。 */
  private evictOne(protectSlot: number): boolean {
    const pool = this.pool;
    let victim: MissileRuntime | null = null;
    let best = -1;
    for (let i = 0; i < pool.highWater; i++) {
      const rt = pool.at(i);
      if (rt.state === MissileState.DEAD || i === protectSlot) continue;
      const score = rt.state === MissileState.EXPLODING ? 1e9 - rt.explodeTicksLeft : rt.ageTicks;
      if (score > best) {
        best = score;
        victim = rt;
      }
    }
    if (victim === null) return false;
    this.stats.evicted++;
    this.terminate(victim);
    return true;
  }
}
```

```ts
import { MissileState } from './missile-types.js';

describe('acquire / release', () => {
  it('hands out INIT records in ascending slot order at first', () => {
    const p = new MissileObjectPool(4);
    for (let i = 0; i < 3; i++) {
      const rt = p.acquire()!;
      expect(rt.handle).toBe(i);
      expect(rt.state).toBe(MissileState.INIT);
    }

  });

  it('handle round-trips to the same record', () => {

    const rt = p.acquire()!;
    const h = p.handleOf(rt);
    expect(p.get(h)).toBe(rt);
    expect(p.isValid(h)).toBe(true);
  });

    expect(p.isValid(h1)).toBe(false);
    expect(p.release(h1)).toBe(false); // 重複釋放

    expect(rt2).toBe(rt); // LIFO:同一個槽位、同一個物件
```

```ts
function zigzagSpec(patch: Partial<F04Params> = {}): MissileSpec {
  const behavior: F04Params = { family: 'F04', stepJitterDeg: 30, retargetEveryTicks: 3, ...patch };

/** 與管理器相同的呼叫方式:update 之前 ageTicks = k,之後 +1。 */
function runZigzag(spec: MissileSpec, seed: number, ticks: number, phi0 = 40) {
  const env = createBehaviorEnv(new TargetRegistry(), 2);
  const rt = makeRt(0, 0, phi0, spec, seed);
  F04_ZIGZAG.init(rt, spec, env);
  const phis: number[] = [];
  const xs: number[] = [];
  for (let k = 0; k < ticks; k++) {
    rt.ageTicks = k;
    F04_ZIGZAG.update(rt, spec, env);
    phis.push(rt.phi);
    xs.push(rt.x, rt.y);
  }
  return { rt, phis, xs };
}
```

```ts
// ───────────────────────── 確定性回放 ─────────────────────────

describe('deterministic replay', () => {
  function runScenario(worldSeed: number): { trace: number[]; hits: number } {
    const charged: F04Params = { family: 'F04', stepJitterDeg: 40, retargetEveryTicks: 2 };
    const spirit: F02Params = {
      family: 'F02',
      turnRateDegPerTick: 8,
      acquireRadiusPx: 600,
      reacquire: true,
      fallback: 'straight',
    };
    const specs = [
      specOf('charged', {
        motion: { speed: 6, accel: 0, maxSpeed: 6 },
        lifetime: { maxLifeTicks: 40, rangePx: null },
        collision: { radiusPx: 10, pierce: 0 },
        behavior: charged,
      }),
      specOf('spirit', {
        motion: { speed: 6, accel: 0, maxSpeed: 6 },
        lifetime: { maxLifeTicks: 60, rangePx: null },
        collision: { radiusPx: 10, pierce: 0 },
        behavior: spirit,
      }),
      specOf('spear', {
        motion: { speed: 8, accel: 0, maxSpeed: 8 },
        lifetime: { maxLifeTicks: 30, rangePx: null },
        collision: { radiusPx: 10, pierce: UNLIMITED_PIERCE },
      }),
    ];
    const targets = new TargetRegistry();
    const units = Array.from({ length: 6 }, (_, i) => makeUnit(80 + i * 40, -100 + i * 60));
    units.forEach((u) => targets.createUnit(u));
    const mgr = new MissileManager({ specs, targets, worldSeed, capacity: 128 });

    const trace: number[] = [];
    for (let t = 0; t < 120; t++) {
      units.forEach((u, i) => {
        u.x += Math.cos(t * 0.1 + i);
        u.y += Math.sin(t * 0.13 + i);
      });
      if (t % 4 === 0) {
        mgr.spawn(0, 0, 0, (t * 37) % 360, 1);
        mgr.spawn(1, 0, 0, (t * 53) % 360, 1);
      }
      if (t % 7 === 0) mgr.spawn(2, 0, 0, (t * 11) % 360, 1);
      mgr.step();
      for (let i = 0; i < mgr.pool.highWater; i++) {
        const rt = mgr.pool.at(i);
        if (rt.state !== MissileState.DEAD) {
          trace.push(i, rt.state, rt.x, rt.y, rt.phi, rt.rngState, rt.hitCount, rt.targetId);
        }
      }
    }
    trace.push(mgr.stats.spawned, mgr.stats.hits, mgr.stats.died);
    return { trace, hits: mgr.stats.hits };
  }

  it('same world seed → bit-identical trajectories (F01 + F02 + F04 mixed, with collisions)', () => {
    const a = runScenario(7);
    const b = runScenario(7);
    expect(a.trace.length).toBeGreaterThan(1000);
    expect(a.hits).toBeGreaterThan(0);
    expect(a.trace).toEqual(b.trace);
  });

  it('a different world seed produces different zig-zag trajectories', () => {
    expect(runScenario(7).trace).not.toEqual(runScenario(8).trace);
  });

  it('per-missile seeds depend only on (worldSeed, spawn order)', () => {
    const spec = specOf('z', {
      behavior: { family: 'F04', stepJitterDeg: 30, retargetEveryTicks: 1 },
      lifetime: { maxLifeTicks: 50, rangePx: null },
    });
    const seeds = (): number[] => {
      const { mgr } = setup([spec], { worldSeed: 99, hooks: null });
      const hs = [mgr.spawn(0, 0, 0, 0), mgr.spawn(0, 0, 0, 0), mgr.spawn(0, 0, 0, 0)];
      return hs.map((h) => mgr.pool.get(h)!.rngState);
    };
    const s = seeds();
    expect(s).toEqual(seeds());
    expect(new Set(s).size).toBe(3);
  });
});
```

## 已知限制

1. **穿透過快的投射物可能漏掉目標**(只在終點檢測)。若之後遇到,最直接的修法是在 `resolveHits` 前加入「起點到終點的線段採樣」。
2. **F02 每 tick 索敵是 O(單位數)**,200 顆追蹤彈 × 數百單位仍然很便宜,但單位數上千時需要空間分格。
3. **`evict-oldest` 掃描是 O(highWater)**,只在池滿時觸發,不在常態路徑。
4. 出現在鉤子裡的 `rt` 是會被池重用的記錄,不能保存引用,與 3-A 的約定一致。
