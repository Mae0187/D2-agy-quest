# Skill names: English and Traditional Chinese, paired by tree cell

Each skill is identified by the cell it occupies on the 3-wide, 6-tall tree grid: the English name comes from SkillDesc.txt's `SkillRow`/`SkillColumn`, and the Chinese from the in-game screenshots the user supplied. Matching on the coordinate rather than on list order is what makes the pairing reliable - the two sources disagree about sequence but agree about position.

**210 of 210 cells matched.**

Chinese is transcribed verbatim from the screenshots: classic Taiwanese client for the six classes (Traditional), and a tabbed window with Simplified overlays for the three sorceress trees. Variant characters are kept as the screenshots write them - 火燄箭, 火燄石魔 and 火燄復甦 use 燄 while 火焰爆震 uses 焰.
