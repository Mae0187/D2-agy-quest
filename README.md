
- `[Shift / R]`：走跑開關切換 (Toggle Mode)。
- `[Q]`：輪轉腳底正統雙層靈氣（神聖之火 / 神聖冰凍 / 神聖衝擊 / 狂熱 / 專注 / 力量 / 庇護所 / 審判 / 荊棘 / 精準祝福 / 無，全 10 種正統靈氣庫完整保留並支援全職業輪轉）。
