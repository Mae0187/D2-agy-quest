# 三、MODE B：True D2 Map Mode

第二階段才開始：

```text
DS1
 ↓
DT1
 ↓
Isometric Map
 ↓
Floor / Wall / Roof
 ↓
Entity Position
 ↓
DCC / COF
```

這時候你才是在做真正的 D2 renderer。

Phrozen Keep 的資料格式整理把 D2 資產的角色分工講得很清楚：

| 格式     | 用途                       |
| ------ | ------------------------ |
| `.COF` | 動畫控制                     |
| `.DC6` | UI、面板、部分動畫               |
| `.DCC` | 角色、怪物、物件、特效動畫            |
| `.DS1` | 地圖資料                     |
| `.DT1` | Floor / Wall / Roof tile |
| `.DAT` | Palette / Colormap       |
| `.WAV` | 音效與語音                    |

([Phrozen Keep][2])

而現成的 D2 開源實作也把 `DS1/DT1`、`DCC/COF`、palette、world、render 分開處理；`libd2` 目前甚至把 DS1/DT1 與 DCC/COF parser、world、render 明確拆成獨立模組。([GitHub][3])

# 十二、建立一個「D2 Combat Director」

這會讓你的畫面活起來。

例如：

```javascript
class CombatDirector {
    onAgentEvent(event) {

        switch (event.type) {

            case "thinking":
                this.enterThinking();

                break;

            case "tool_call":
                this.castRandomSkill();

                break;

            case "error":
                this.spawnElite();

                break;

            case "retry":
                this.startBossPhase();

                break;

            case "success":
                this.completeWave();

                break;
        }
    }
}
```

然後：

```text
CLI Event
 ↓
Director
 ↓
World Simulation
 ↓
Actors
 ↓
Renderer
```

這個中間層非常重要。

# 二十八、還有一個法律 / 發布上的實務問題

你現在使用：

```text
Diablo II MPQ

Spriters Resource 素材
```

最好把：

```text
Engine code
```

與：

```text
Game assets
```

分開。

尤其不要把完整 Blizzard MPQ 資產直接打包進 GitHub repository 或公開安裝包。

OpenD2 自己也採用「engine 使用原始遊戲檔，但不隨專案重新分發遊戲內容」的模式，而且其 README 明確提到這樣做也是為了降低法律問題。([GitHub][10])

另外，Fandom 該分類頁標示社群內容一般採 CC-BY-SA、但「除非另有註明」；這不等於 Diablo II 原始遊戲資產本身因此取得與遊戲內容相同的再發布權利，所以兩者不要混為一談。([暗黑破壞神百科][1])
