# 《暗黑破壞神2：毀滅之王》AI Agent 戰鬥監控看板：系統架構與技術規格總覽 (specs/00)

---

## 1. 核心定位與產品邊界
本專案為 **AI Agent 即時狀態與 Token 戰鬥監控看板**，核心目標是將 AI Agent 的終端指令、推理思考、工具調用、大招執行、錯誤重試與任務完成狀態，映射為具備極高打擊感、手感與視覺衝擊力的暗黑 2 地牢冒險畫面。

* **專案本質**：監控看板與視覺反饋層，**絕非 100% 伺服器模擬器**。
* **資源聚焦**：完全捨棄使用者不可見的無用伺服器運算（如底層傷害抗性衰減公式、複雜仇恨池計算），專注於視覺還原、粒子特效衝擊力與流暢打擊反饋。

## 3. 三級技能分層策略 (3-Tier Skill Taxonomy)
為化解全 210 個技能個別硬編碼造成的架構失控，嚴格採取三級分層：
* **A 級（20~30 個核心招牌技能）**：直接對應 Agent 核心狀態，手工打磨全套前搖判定幀、彈道與受擊反饋。
* **B 級（15~20 個行為家族原語庫）**：將暴雪原版底層 C 函式（`CltDoFunc`、`SrvDoFunc`、`CltHitFunc`）抽象為通用模組，技能僅需組合原語並填入原廠參數。
* **C 級（換皮與衍生技能）**：100% 共用 B 級行為原語，僅切換精靈圖貼圖與調色盤。

## 4. 真理源階層順序 (Truth Source Hierarchy)
在數據獲取與素材管線中，嚴格遵守單向優先順序：
1. **第一順位（唯一真理源）—— 本機原廠 MPQ 數據庫**：
   位於 `Diablo2-Agent-Monitor/tools/mpq_raw/` 的 `MonStats.txt`、`Skills.txt`、`Missiles.txt`、`Overlay.txt`、`AnimData.D2` 與原生 DCC。判定幀、動作速度與彈道規格一律以此為準。
2. **第二順位（實體動作輔助）—— The Spriters Resource**：
   五大 Boss 與雜兵實體透明精靈圖之快速獲取來源。注意：該站已丟失原始錨點，需用接地工具二次校準；且**該站完全未收錄技能投射物與法術粒子**。
3. **第三順位（戰鬥導演與數值參考）—— Diablo Archive 怪物百科**：
   僅作為首領招式配置、種族（惡魔/不死/野獸）與戰鬥導演輪替邏輯之文本參考。
4. **第四順位（視覺 QA 肉眼標竿）—— Diablo Fandom 技能圖片庫**：
   僅作為粒子大小與光效特徵的「目視驗收對照標準」，嚴禁直接下載作為透明遊戲素材。
