Chapter One : Tools of the Trade

1.1 The Need :

The first step to take when beginning a conversion is to choose the tools. They're divided into 3 categories :

  1. The Extraction Tools : These tools are used to grab animations from other games. Depending on which game
    you'll grab animations from, different applications are available. Each game have its own file formats
    for storing animations, there are as many programs. Basically, they have to output animation into an editable
    format, animated GIF or animated PNG.

  2. The Animation Editing Tools : These tools are used to edit and alter gif animations that came from the tools
    above. Two are now references in the modmaking scene. They are Gamani GIF Movie Gear and Jasc Animation
    Shop Pro. Both come as shareware or demo version, but for a little money, they become a worthy investment.

  3. The Animation Conversion Tools : The meat loaf. They convert GIF into DCC files ready to be plugged to
    your mod. Currently there is only one such tool : CV5 and its CVDCC Add-On.

1.2 Getting the tools :

Now that we know what we need, it's time to load up your modem and grab them over the Internet ...

Most Extraction Tools can be found on fansites of the appropriate game. Games that support a modmaker community
are often a good choice because other people may have already created such tools. That's why it's easier to get Black
Isle game animations than animations from The Sims for example. The one we'll use in this tutorial is called Infinity Explorer.
It's used to extract files from the Baldur's Gate series of games. You can get it at www.teambg.com

The Animation Editing applications can be downloaded at their editor's website.
For Gamani Movie Gear, check out www.gamani.com.
For Animation Shop Pro, check out www.jasc.com.

Finally, getting CV5 and its addon is doable here at http://user.cs.tu-berlin.de/~mickyk.

1.3 First shot :

OK, now you've downloaded all the stuff you need from various websites and installed them.
So, now you have on your hardrive the following programs :

  • Infinity Explorer.
  • Gif Movie Gear and/or Animation Shop Pro
  • CV5 and its dcc Addon.
  • Any of Black Isle Baldur's Gate-like game.

We're going to do a very quick overview of Infinity Explorer for people who never touched it.

1.3.1 Infinity Explorer :

Launch Infinity Explorer. You'll obtain the following screenshot.



In the dialog box, choose the folder where your game is installed. Here I chose Planescape Torment (you may have a different game installed).
After selecting the folder, click on OK. Infinity Explorer now loads the game archives and displays a tree
view where all the game components are listed.

Head to the Graphics (BAM) section and click on the little (+).
Like in Windows explorer, you could navigate into this treeview to seek files.
When you select an animation, the screen looks like this :

Take a closer look at the upper right corner of the window :


This part is composed of four noticeable parts :

  • The Animations indicator : Each Baldur's Gate animation is composed of one or many animations, containing the directions of the animation,
    like in Diablo II. By using the two arrow buttons, you navigate trough all the animation files of an animation.

  • The Frames Indicator : By using the arrows, you navigate trough the animation frame per frame. Each frame is displayed in the
    graphics box under the indicator.

  • The Graphics Box : It shows frames and animations of the currently selected animation. Its size may vary with the animation selected.

  • The Play Button : Obviuosly, it's used to play the anim in the Graphics box.

When you have selected an animation that you want to export into GIF, click on the Export button.

These archives also contains item graphics, AI script etc ...
Explore them for yourself to get acquainted with Infinity Explorer.
